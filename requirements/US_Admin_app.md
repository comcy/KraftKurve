# User Story: Administration Application

As an administrator, I want to manage users, invites, and the exercise catalog so that the system remains organized and secure.

## Description
The Admin app allows maintaining system settings and user management. It is a restricted micro-app accessible only by administrators.

## Acceptance Criteria

### Functional
- [ ] User management: List, activate, and deactivate users.
- [ ] Invite management: Generate and track registration invites.
- [ ] Exercise catalog: Create, edit, and delete exercises (global data).
- [ ] Restricted access: Redirect non-admin users away.
- [ ] Deep-linking: Admin sub-features are accessible via unique URLs.

### Non-Functional
- [ ] Shared data-access libraries for system data.
- [ ] Material table/list components for data management.
- [ ] Responsive data views.
