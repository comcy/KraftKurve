# User Story: Training Tracker Application

As an athlete, I want to log my workouts and see my previous performance so that I can track my progress effectively.

## Description
The Training app is the core tracker for gym sessions. It allows logging sets, reps, and weights for various exercises.

## Acceptance Criteria

### Functional
- [ ] Start a new training session (Empty or from Template).
- [ ] Add exercises to the current session from the catalog.
- [ ] Log multiple sets per exercise (Weight, Reps).
- [ ] Display "Last Time" values for the current exercise.
- [ ] Save and complete training sessions.
- [ ] View training history.

### Non-Functional
- [ ] Optimized for quick data entry (large buttons, minimal typing).
- [ ] Local-first: Workouts can be logged offline.
- [ ] Real-time progress indicators.
