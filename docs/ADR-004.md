# ADR-004: Tactical Logbook Design System

**Status:** Accepted
**Date:** 2026-05-24

## Context
The application needed a distinct visual identity that reflects its purpose as a high-performance training tool.

## Decision
Adopt a "Cyber-Athletic" aesthetic called "Tactical Logbook". Key elements:
- **Typography**: `Press Start 2P` for headlines, `JetBrains Mono` for data.
- **Color Palette**: High-contrast dark theme (#131313) with Yellow (Primary), Magenta (Secondary), and Green (Tertiary) accents.
- **Components**: Brutalist design with 4px rounding, "tape" headers, and archival file metaphors.

## Consequences
- **Pros**: Unique brand identity, high legibility in gym environments, data-centric focus.
- **Cons**: Diverges from standard Material Design defaults, requiring custom component styling.
