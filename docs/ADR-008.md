# ADR-008: Shared Workout Details Library

## Context
The `WorkoutDetailSheetComponent` was initially created as a local component within the dashboard feature of the mobile app. However, the same detailed workout view is required in other parts of the application, specifically the training mission control center.

## Decision
We decided to extract the `WorkoutDetailSheetComponent` into a shared feature library named `lib-training-feature-details`. This follows our architectural principle of "Library-based feature organization" (ADR-002) and ensures:
1. **Reusability**: The detail sheet can now be used in both Dashboard and Training features without code duplication.
2. **Consistency**: Changes to the detail view will automatically propagate to all entry points.
3. **Modularization**: Decoupling the detail view from the dashboard makes both components easier to maintain and test.
