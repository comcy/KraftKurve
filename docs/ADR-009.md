# ADR-009: Set-by-Set Progression Analysis (Virtual Trainer)

## Context
The previous "Progression IQ" implementation used a simple average of weight and reps from the last performance to suggest new targets. This approach ignored the "Fatigue Curve" (how RIR decreases or reps drop across sets), leading to potentially unrealistic or suboptimal suggestions.

## Decision
1.  **Individual Set Analysis**: The algorithm will analyze every set of the previous performance individually.
2.  **Fatigue Curve Evaluation**:
    - **Progressive Overload**: Triggered if *all* sets maintained a high RIR (e.g., >= 2).
    - **Maintenance/Consolidation**: Suggested if RIR reached 0-1 on later sets, indicating the current load is challenging enough.
    - **Deload/Adjustment**: Suggested if Reps dropped significantly across sets (e.g., 10, 8, 6) even with high effort.
3.  **Unified Target**: Instead of suggesting per-set, the Virtual Trainer will output a unified "Proposed Performance" (Sets x Reps @ Weight) representing the goal for the entire exercise.

## Consequences
- **Pros**: Much more accurate suggestions that respect the user's actual recovery and intensity capacity.
- **Cons**: Slightly higher computational complexity on the backend (negligible for the current architecture).
- **Requirement**: Users must consistently log RIR for the algorithm to reach maximum efficiency.
